# 📘 Project Diagrams and System Concepts

This repository contains a collection of my system design diagrams created using [draw.io](https://draw.io), illustrating the core architecture, control flow, and system logic of various projects I've worked on.

## 🧩 Purpose

These diagrams help me visualize, design, and refine the embedded systems and control logic I develop, ensuring clarity and maintainability throughout each project.

## 🧠 Conceptual Diagrams

Each diagram serves a different purpose in the development lifecycle:

### 1. 🧱 Block Diagram
This diagram shows the high-level system architecture, illustrating the major components (e.g., sensors, microcontrollers, communication interfaces, actuators) and how they interconnect.

> *Purpose:* Understand how hardware modules and subsystems are organized and communicate.

---

### 2. 🔁 Flow Control Diagram
This visualizes the logic flow and decision-making processes used in the firmware or application code.

> *Purpose:* Clarifies algorithm steps, task sequences, and conditional logic (e.g., state machines or task schedulers).

---

### 3. ⚙️ System Control Diagram
Illustrates how different control systems (e.g., motor control, valve control, temperature regulation) interact with inputs and outputs, and how data moves through the system.

> *Purpose:* Captures system dynamics, feedback loops, and control mechanisms.

---

## 🛠️ Tool Used

All diagrams were created using **draw.io** (also known as **diagrams.net**), a powerful online and offline tool for diagramming. I use this platform to represent my knowledge, insights, and development progress clearly and efficiently.

## 📂 Files

You may find `.drawio`, `.png`, or `.svg` files in this directory corresponding to each type of diagram.

This documentation is an integral part of my engineering workflow, combining visual thinking and embedded development. It helps me (and collaborators) stay aligned with system requirements and implementations.
